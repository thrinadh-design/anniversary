# First Anniversary Surprise

A self-contained romantic anniversary website for Chinnu Bava, built with plain HTML, CSS, and JavaScript.

## Run in VS Code

1. Open the `anniversary` folder in VS Code.
2. Install the **Live Server** extension by Ritwick Dey if it is not installed.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Use the demo login: any username, with `forever` as the secret code.

## Personalize

- Add your optional song at `assets/our-song.mp3`.
- Replace the four memory placeholders in `index.html` with personal image elements or background images.
- The login secret can be changed in `script.js`.
